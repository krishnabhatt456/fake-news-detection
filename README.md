# AI Fake News & Deepfake Detector

An AI-powered web application built using Streamlit, Transformers, and OpenCV that detects fake news text and suspicious manipulated images.

# Features
- Fake news detection using NLP transformer models
- AI-generated / manipulated image analysis
- Ensemble model voting system
- User-friendly Streamlit interface
- Confidence score prediction

# Technologies Used
- Python
- Streamlit
- HuggingFace Transformers
- OpenCV
- NumPy
- PIL

# Run Locally

```bash
pip install -r requirements.txt
streamlit run app.py
